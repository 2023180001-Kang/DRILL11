# DRILL11 자동 무적 런

기존 `pico2d` 소년 예제에 독립된 `AutoRun` 상태 클래스를 추가한 프로젝트이다. 기존 소년 100명, 좌우 이동, 수면 및 깨우기를 유지한다.

## 설치와 실행

검증 환경은 Windows 및 Python 3.13.15이다. 그래픽 실행에는 SDL 창을 열 수 있는 환경이 필요하다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

이미지는 소스 파일의 위치를 기준으로 불러오므로 다른 작업 디렉터리에서도 `main.py`의 경로를 지정해 실행할 수 있다. 이미지 파일은 소스와 같은 폴더에 유지한다.

## 조작

| 키 | 동작 |
| --- | --- |
| `a` | IDLE에서 자동 무적 런 시작 |
| 왼쪽 / 오른쪽 | 일반 이동. AutoRun 중에는 취소하고 누른 방향으로 RUN 전환 |
| 스페이스 | SLEEP에서 깨우기 |
| Escape / 창 닫기 | 종료 |

- AutoRun은 입력 없이 초당 400픽셀로 이동하며 표시 크기는 200 x 200이다. 일반 RUN은 초당 200픽셀, 크기는 100 x 100이다.
- 마지막으로 바라본 방향으로 시작하고, 확대된 이미지의 양 끝을 기준으로 화면 좌우에서 방향을 바꾼다.
- 진입 후 5초가 된 첫 갱신에 IDLE로 돌아온다. 같은 갱신에서 좌우키를 누르면 RUN 전환을 우선한다.
- 키 해제와 상하키는 자동 무적 런을 취소하지 않는다. 누르고 있는 키의 반복 입력은 새 입력으로 처리하지 않는다.
- 좌우키를 모두 유지하면 일반 이동에서는 기존처럼 정지한다. AutoRun 취소 순간에는 새로 누른 좌우키 방향을 우선한다.
- IDLE에서 5초가 지나면 기존처럼 SLEEP에 들어간다. SLEEP에서는 스페이스로 깨운 뒤 `a`를 누른다.
- 소년들은 같은 위치에서 시작하므로 서로 겹쳐 보인다. 이는 기존 100명 구성을 유지한 결과이다.

## 무적 판정

기초 코드에는 체력과 피격 시스템이 없다. 전투 시스템을 새로 만들지 않고 `boy.invincible`로 상태를 조회하며, 피해를 처리할 코드는 `boy.can_take_damage()`가 참인 경우에만 피해를 적용하도록 연동한다. 무적 여부는 현재 상태에서 계산하므로 시간 만료 및 입력 취소 시 자동으로 해제된다. 검증용 피해 호출은 `test_boy.py`에 있다.

## 검증

창을 열지 않는 자동화 테스트:

```powershell
python -m unittest discover -v
```

실제 그래픽 창과 에셋으로 약 5.3초 동안 자동 실행하는 스모크 테스트:

```powershell
python smoke_test.py
```

스모크 테스트는 100명의 확대 렌더링, 양방향 자동 이동, 5초 종료, 재진입 후 취소 및 효과 복원을 검사하고 창을 닫는다. 진행 중 창을 닫거나 Escape를 누르면 검증 중단으로 처리한다. 무창 테스트와 달리 화면 출력이 가능한 환경에서 실행해야 한다.

수동으로 확인할 항목:

1. 실행 직후 `a`를 누르고 놓아도 확대된 소년이 계속 달리는지 확인한다.
2. 좌우 끝에서 이미지가 화면 안에 유지되고 방향과 달리기 이미지가 함께 바뀌는지 확인한다.
3. 5초 후 크기가 복원되고 멈추는지 확인한다.
4. 다시 발동한 뒤 반대쪽 방향키를 눌러 즉시 작은 크기의 일반 이동으로 바뀌는지 확인한다.
5. 키를 모두 놓고 5초 후 수면, 스페이스로 깨우기가 유지되는지 확인한다.
